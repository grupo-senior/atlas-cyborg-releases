# atlas-cyborg-releases

Repositório público que guarda **apenas os pacotes compilados de atualização automática** do Atlas Cyborg (assets `app.zip` dos GitHub Releases).

- Não contém código-fonte, segredos nem instaladores.
- Os pacotes são publicados automaticamente pelo workflow de release do repositório privado `atlas-cyborg`.
- O robô só aplica um pacote depois de conferir o SHA-256 informado pelo Atlas.
- Não instale nada daqui manualmente.
